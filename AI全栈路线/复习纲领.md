**第二层：这份岗真会问的，就这些**  
用你笔记里已经写好的答案，不要另起炉灶。

Next / React（前端只保这层）

- 什么必须 `'use client'`
- RSC 不是 SSR
- `cookies()` 为什么让页面不能静态
- middleware 不能替代鉴权
- hydration mismatch 常见原因

FastAPI / Python

- `def` vs `async def`
- Depends 和中间件怎么选
- SSE vs WebSocket
- `BackgroundTasks` 不是队列
- 鉴权放 Depends，`/health` 不要一刀切

MySQL

- 订单为什么不能只放 Redis
- 金额用整数
- `EXPLAIN` 怎么看有没有走索引
- 深分页为什么慢
- `INNER` / `LEFT JOIN` 别把 LEFT 写成 INNER

Redis

- 旁路缓存：写库成功再删缓存
- 穿透 / 击穿 / 雪崩各防什么
- 计数用 `INCR`，不要 GET 再 SET
- 限流挂了为什么选择放行

Docker

- 镜像 / 容器 / 卷
- Compose 里为什么不能写 `localhost`
- `depends_on` 不等于 MySQL 已就绪

**第三层：被问到就承认边界**  
K8s、Prometheus、消息队列、ERP 集成，一句话：「概念知道，生产没用过。」不要为这几项重新背书。

前端可以松的：CSS 边角、Vue 源码、Webpack 细节、微前端、小程序、RN。这份 JD 几乎不会靠这些分胜负。React 状态、hooks 规则、闭包、事件循环还要能讲，但目标是「卡住能捡起来」，不是 2018 年那种清晰度。

记的方法也换一下：每道题只留 4 句——是什么、为什么要、我怎么做、坑在哪。出声讲 90 秒，讲不利索再看笔记。通读会制造「我都学过」的错觉，开口才会暴露真的松在哪。

你不是样样通样样松，是主战场从页面变成了「页面 + 接口 + 数据」。按链路记，前端会在项目里自己回来；按知识点补，会越补越虚。
