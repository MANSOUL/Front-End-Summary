# 全队约定

所有人的 AI 都先读这份文件，再读 `BRIEF.md`。

## 技术
- React 函数组件 + TypeScript
- 业务逻辑放 `src/lib`，组件不直接操作 localStorage
- 类名用现有 CSS，不引入新的视觉体系
- 禁止无关重构

## 工单怎么写给 AI
每张工单必须带齐五段：目标、约束、上下文、输出、质量要求。复制出来的提示词按这个顺序，不要发挥。

## 切片规则
- 按能演示的路径切，不按前端/后端/测试切
- 一次只做一张工单
- 做完把状态打到「待审」，由许澄或当班审查的人看

## 门禁
- 主路径能亲手点一遍
- `npm test` 通过
- diff 不包含工单范围外的文件
- 谁提的改动，谁对 AI 生成的代码负责
