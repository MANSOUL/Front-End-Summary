W3C 标准不是某一个标准，而是 W3C（万维网联盟）制定的一系列 Web 技术规范的总称。它的目标是让 Web 保持开放、可互操作、可访问、国际化，避免浏览器厂商各自为政导致网页不兼容。

1. W3C 是什么

W3C 全称 World Wide Web Consortium，1994 年由 Tim Berners-Lee 创立，是 Web 领域最重要的国际标准组织之一。它本身不强制浏览器执行，而是发布“推荐标准”（W3C Recommendation），由浏览器、框架和开发者自愿遵循。

2. 覆盖哪些标准

W3C 标准涵盖 Web 的多个层面：

· 结构：HTML、XML、XHTML
· 表现：CSS
· 行为与接口：DOM、Web API、Web Workers、IndexedDB、Web Storage
· 图形与多媒体：SVG、MathML、Canvas、WebRTC
· 可访问性：WCAG、WAI-ARIA
· 安全与身份：WebAuthn、Web 支付、内容安全策略等

注意：JavaScript 语言核心（ECMAScript）由 ECMA TC39 制定，不是 W3C；HTML 和 DOM 现在主要由 WHATWG 维护 Living Standard，W3C 也参与并发布快照。所以“W3C 标准”有时是泛指 Web 标准。

3. 制定流程

一个规范通常经历：

1. Working Draft（工作草案）
2. Candidate Recommendation（候选推荐）
3. Proposed Recommendation（提案推荐）
4. W3C Recommendation（W3C 推荐标准）

到达 Recommendation 就是正式标准。此外还有 Note、Working Group 等。

4. 和其他组织的关系

Web 标准是多个组织分工协作的结果：

· W3C：CSS、SVG、WCAG、WebRTC、WebAuthn 等
· WHATWG：HTML、DOM、Fetch、URL 等 Living Standard
· ECMA TC39：ECMAScript（JavaScript 语言核心）
· IETF：HTTP、TCP、DNS、WebSocket 协议等
· Khronos：WebGL、WebGPU 等

5. 为什么重要

· 保证跨浏览器兼容，减少前缀和 hack。
· 提升可访问性，让残障用户也能使用。
· 利于 SEO 和语义化。
· 支持设备无关，适配 PC、移动端、平板。
· 让 Web 长期可维护，不被单一厂商控制。

6. 总结

“W3C 是制定 Web 标准的国际组织，标准包括 HTML、CSS、DOM、SVG、WCAG 等。它的目标是开放、互操作和可访问。虽然 HTML 和 DOM 现在由 WHATWG 维护，ECMAScript 由 ECMA 制定，但 W3C 标准仍是 Web 生态的基石。前端遵循 W3C 标准，主要是为了保证兼容性、可访问性和长期可维护性。”
