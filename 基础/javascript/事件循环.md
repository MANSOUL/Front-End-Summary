### 原因

JavaScript 是一门单线程语言，意味着同一时间只能做一件事，但这并不意味着阻塞，而实现非阻塞方式就是事件循环；

在JavaScript中任务可分为：

- 同步任务：立即执行的任务，直接进入到主线程执行
- 异步任务：异步执行的任务，如网络请求、定时器、Promise等

同步任务进入主线程中执行，异步任务则进入任务队列，执行完毕后，同步任务执行完毕后，就去任务队列中读取任务，推入主线程执行；这个过程不断重复就是事件循环。


#### 宏任务和微任务

任务可分为宏任务和微任务，同步任务执行完毕后会先读取微任务队列，后读取宏任务队列；
一次事件循环就是：执行完当前的宏任务，就去清空微任务队列；
接着再取出下一个宏任务。

宏任务有：
```
script（外层同步代码）
setTimeout
setInterval
setImmediate(Node)
```

微任务有：
```
Promise.then
Promise.nextTick
```
