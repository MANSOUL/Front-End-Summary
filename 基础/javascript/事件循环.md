### 原因

JavaScript 是一门单线程语言，意味着同一时间只能做一件事，但这并不意味着阻塞，而实现非阻塞方式就是事件循环；

在JavaScript中任务可分为：

- 同步任务：立即执行的任务，直接进入到主线程执行
- 异步任务：异步执行的任务，如网络请求、定时器、Promise等

同步任务进入主线程中执行，异步任务则进入任务队列，异步执行完毕后，就进入了事件队列；同步任务执行完便去事件队列中读取任务，推入主线程执行；这个过程不断重复就是事件循环。


#### 宏任务和微任务

为了实现任务插队，又将事件队列内的任务分为宏任务和微任务；微任务拥有更高的优先级，当事件循环遍历队列时，先检查微任务队列，如果里面有任务，就全部拿来执行，执行完之后再执行一个宏任务。执行每个宏任务之前都要检查下微任务队列是否有任务，如果有，优先执行微任务队列.

![事件循环图](../images/event-loop.awebp)

宏任务有：
```
script（外层同步代码）
setTimeout
setInterval
setImmediate(Node)
IO
UI事件
postMessage
```

微任务有：
```
Promise.then
Promise.nextTick
Object.observe
MutationObserver
```
