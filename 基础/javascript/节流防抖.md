#### 节流

节流函数在一个时间段内只执行一次

```js
function throttle (fn, threshhold = 500, context = null) {
    let lastTime = Date.now()
    let timer = null
    return function throttled(...args) {
        const currentTime = Date.now() 
        const pastTime = currentTime - lastTime
        clearTimeout(timer)
        if (pastTime >= threshhold) {
            fn.apply(context, args)
            lastTime = currentTime
        } else {
            // 最后一次
            timer = setTimeout(() => {
                fn.apply(context, args)
            }, threshhold - pastTime)
        }
    }
}
```

#### 防抖

函数在一个时间段后执行，若在此时间段内再次执行防抖函数，则取消当前回调并安排下一次回调。

```js
function debounce (fn, delay = 500, context = null) {
    let timer = null
    return function debounced (...args) {
        clearTimeout(timer)
        timer = setTimeout(() => {
            fn.apply(context, args)
        }, delay)
    }
}
```
