# 进制转换及元算

## 正整数转为二进制
以21为例：
```
21/2 ...... 1
10/2 ...... 0
5/2  ...... 1
2/2  ...... 0
1
```
得二进制：`10101`

## 负整数转为二进制
正整数二进制取反，在加1。
以-21为例：
```
10101 => 01010 => 01011
```

## 小数转为二进制
乘2取整直到小数位为0。
以0.125为例：
```
0.125 * 2 = 0.25 .... 0
0.25 * 2 = 0.5   .... 0
0.5 * 2 = 1.0    .... 1
```
得二进制位：`0.001`

0.1为：
```
0.0001 1001 1001 无限循环
```
0.2为：
```
0.0011 0011 0011 无限循环
```

## 二进制小数转为十进制
以二进制`0.001`为例：
```
0 * 2^-1 + 0 * 2^-2 + 1 * 2^2 
=====
0 * 1/2 + 0 * 1/4 + 1 * 1/8
=====
0.125
```

## 二进制加法
以`0.125 + 0.125`为例：
```
0.001
+
0.001
=
0.010
```

## 计算机中整数的表示
4个字节表示整数。
以9为例,二进制为：`0000 0000 0000 0000 0000 0000 0000 1001`

## 计算机中浮点数的表示
以9.0为例,
遵循IEEE 754换算标准
>(-1)^s表示符号位，当s=0，V为正数；当s=1，V为负数。
>M表示有效数字，大于等于1，小于2。
>2^E表示指数位。

IEEE 754规定，对于32位的浮点数，最高的1位是符号位s，接着的8位是指数E，剩下的23位为有效数字M。
![32位浮点数](http://image.beekka.com/blog/201006/bg2010060601.png)
对于64位的浮点数，最高的1位是符号位S，接着的11位是指数E，剩下的52位为有效数字M。
![64位浮点数](http://image.beekka.com/blog/201006/bg2010060602.png)

```
9.0 ==> 1001.0 ==> 1.001 * 2^3
```
第一位符号为0，有效数字M等于001后面再加20个0,指数E：3 ==> 3 + 127 = 130，10000010
所以，写成二进制形式，应该是s+E+M，即0 10000010 001 0000 0000 0000 0000 0000。这个32位的二进制数，还原成十进制，正是1091567616。
