# 面试题
doctype用来干嘛的？
用于告诉浏览器当前HTML的版本，浏览器根据doctype决定是以兼容模式还是标准模式对文档进行渲染。
补充：html5不基于SGML,SGML标签和属性名大写，但到了h5标准为标签名和属性名小写

cookie,localStorage,sessionStorage的区别
1. 都可以用于存储信息的
2. 大小限制（cookie 5k,localStorage，sessionStorage 5M)
3. cookie会随着请求一起发送且可设置过期时间
4. localStorage不会过期，除非手动删除
5. sessionStorage在网页关闭之后就会消失
补充storage api,setItem,getItem,clear,remoteItem,length,key

href,src的区别
1. href用于文档和外部资源建立起一个链接，src用于替换元素
2. href加载不会导致页面解析暂停
3. src在下载，便衣，执行时页面解析会暂停
